Bem-vindo

Esta pasta reúne a documentação de gestão do segundo período do projeto (Portal do Curso de Sistemas de Informação), produzida pela Fábrica de Software. Substituímos o formato Word tradicional por documentação HTML interativa, versionada no Git — prática comum em equipes de produto e engenharia.

Por que HTML em vez de Word? Documentação viva e rastreável no repositório; Gantt interativo com dependências; backlog editável; visual alinhado ao Design System gov.br do portal; exportação para PDF via impressão do navegador (Ctrl+P) quando necessário.

Como usar

  1. Abra os arquivos HTML no navegador (duplo clique ou servidor local).
  2. Revise placeholders [Gerente] e [Colega 1–3] com a equipe.
  3. Para PDF: abra o Business Case ou o charter → botão de exportação / Ctrl+P → «Salvar como PDF».
  4. Atualize assets/backlog.js e assets/gantt-data.js a cada sprint.
